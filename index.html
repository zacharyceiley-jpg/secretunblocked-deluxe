Enable Deluxe Cloud Saves for this game

Games must include this small bridge in their own code. Deluxe cannot read another site's private localStorage automatically, but this lets a compatible embed send its save data to the signed-in player's account.

function saveToDeluxe(saveData) {
  window.parent.postMessage({ type: "deluxe:save", data: saveData }, "*");
}
function loadFromDeluxe(onLoaded) {
  function receive(event) {
    if (event.source !== window.parent || event.data?.type !== "deluxe:load") return;
    window.removeEventListener("message", receive);
    onLoaded(event.data.data ?? null);
  }
  window.addEventListener("message", receive);
  window.parent.postMessage({ type: "deluxe:load-request" }, "*");
}
// Example: saveToDeluxe({ level: 4, coins: 120 });

Call saveToDeluxe(yourSaveObject) whenever the player makes progress, and use loadFromDeluxe(data => ...) when the game starts. Only save JSON data, and ask the player to sign in to Deluxe.

About Us

What Deluxe is, what information it uses, and why.

What is Deluxe?

Secret Unblocked Deluxe is a platform for discovering and sharing games, creating a profile, and using community features such as friends, messages, notifications and game collections.

Information we use

When you create an account or use Deluxe, the platform may process information you provide or create while using its features, including:

  • Account details: your email address for account sign-in, and the username you choose.
  • Profile and preferences: profile details such as your avatar and settings such as selected themes and game preferences.
  • Game content: game titles, descriptions, links, icons, images, tags and other information you submit when publishing or editing games.
  • Platform activity: information needed for features such as playtime, ratings, collections, unlocks, purchases and notifications.
  • Community activity: information needed to operate friend requests, presence, and messages or chat features you choose to use.

Why we use it

Deluxe uses this information to create and manage accounts, display profiles and games, save preferences and progress, operate community features, deliver notifications, administer the platform, help keep the service reliable, and review content submitted to the platform.

Where information is stored

Deluxe uses Supabase for its account authentication and online database services. Information is handled by those services to provide the features described above. Do not include passwords or other sensitive personal information in public profile fields, game descriptions, or community posts.

What other users can see

Some information is intended to be public, such as your username, profile details you choose to display, and published game information. Community messages and other interactions may be visible to the people or groups involved. Think carefully before sharing personal information with other users.

External websites

Games and links submitted by users may take you to websites outside Deluxe. Those websites operate independently and have their own privacy practices. Check their information before using them.

Sign-in options

Deluxe currently provides email-and-password account sign-in through its account system. There is no Continue with Google sign-in option.

This page describes how the current Deluxe features are intended to use information. If a feature changes, this explanation should be updated to match it.
